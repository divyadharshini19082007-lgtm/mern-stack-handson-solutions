# Activity 3: Real-world Scenario Mapping Students identify common applications they use daily and map their frontend, backend, and database components.

Aim: To identify the frontend, backend, and database components of everyday applications and understand how they work together.

## Solution

In this activity, students select familiar applications and identify their main components.

## Component mapping table

| Application | Frontend                       | Backend                            | Database                     |
| ----------- | ------------------------------ | ---------------------------------- | ---------------------------- |
| Amazon      | Product pages and cart         | Order processing                   | Products and orders          |
| Swiggy      | Restaurant and menu screens    | Order and delivery management      | Restaurants and orders       |

| YouTube     | Video player and search screen | Video delivery and recommendations | Video metadata and user data |

## How the components work together

Frontend

User clicks “Place Order”

Backend

Validates and processes the order

Database

Stores the order details

Response

Frontend displays “Order placed successfully”

## Expected outcome

Students understand the differences between frontend, backend, and database components and learn how these components work together to build real-world applications.

Conclusion: Every modern application uses a frontend to interact with users, a backend to process requests, and a database to store and retrieve information. Understanding these components provides a foundation for learning full-stack development, including the MERN stack.
