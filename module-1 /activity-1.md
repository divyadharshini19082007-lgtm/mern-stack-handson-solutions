# Activity 1: How the Internet Works
Students simulate the interaction between a browser, server, and database to understand how requests are processed and responses are returned. 
# Solution

We can demonstrate this activity using three students acting as the Browser, Server, and Database.

3\. Database

The database stores or retrieves the required information and returns it to the server.

Server prepares the response

Response to Browser

The browser displays the result, such as “Login successful” or “Invalid password.”

## Example demonstration

Suppose a student logs in to a college website.

1. The Browser sends the student's username and password to the server over a secure connection.
2. The Server validates the login details.
3. The Database provides the relevant stored user information.
4. The Server checks the result and sends a response.
5. The Browser displays the dashboard if the login succeeds or an error message if it fails.

## Expected outcome

Students understand that the browser sends requests, the server processes them, and the database stores or retrieves information. The server then sends a response back to the browser.

Conclusion: The internet enables communication between clients and servers using protocols such as HTTP and HTTPS, allowing users to access websites and online services.
